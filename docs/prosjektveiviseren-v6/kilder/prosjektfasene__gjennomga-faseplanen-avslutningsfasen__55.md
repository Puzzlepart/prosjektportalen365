# Gjennomgå faseplanen for avslutningsfasen

Start avslutningsfasen med å gjennomgå faseplanen for avslutningsfasen, som ble utarbeidet i gjennomføringsfasen.

Opprettet: 07. april 2022
Sist endret: 12. juni 2026

Formålet er å sikre at alle involverte forstår hva som skal gjøres før prosjektet kan avsluttes. Gå gjennom aktiviteter, ansvar, frister, gjenstående / uferdig arbeid, dokumentasjon, kontrakter, økonomi, plan for nyttestyring og sluttrapport.
Dersom løsninger allerede er overlevert underveis, bør gjennomgangen særlig avklare hva som gjenstår før prosjektet kan oppløses. Det kan gjelde dokumentasjon, erfaringsoverføring, formelle beslutninger, gjenstående / uferdig arbeid, økonomi, kontrakter eller etablering av videre forvaltnings- og produktansvar.
**Gjennomgangen av faseplanen bør avklare:**

- hvilke avslutningsaktiviteter som gjenstår, og hvem som har ansvar for disse.
- hvilke dokumenter som skal ferdigstilles
- gjenstående / uferdig arbeid som må avklares
- hvilke kontrakter og økonomiske forhold som må lukkes
- hvilke metoder, relevant dokumentasjon fra arbeidsverktøy som er benyttet, og erfaringer som skal overføres
- hvordan BP5 skal forberedes
