# Nettverket for prosjekt-, program- og porteføljestyring

Nettverket er eit brukardrive samarbeid for erfaringsutveksling og gjensidig inspirasjon. Føremålet er å styrkje offentlege verksemder si evne til god prosjekt-, program- og porteføljestyring.

Opprettet: 07. juni 2022
Sist endret: 29. juni 2026

PPP-nettverket er ein møteplass for offentlege verksemder som arbeider med prosjekt-, program- og porteføljestyring. Nettverket legg til rette for erfaringsdeling, fagleg utvikling og gjensidig inspirasjon på tvers av forvaltninga.
Nettverket ser òg på korleis styring heng saman med produktorganisering, og korleis prosjekt, program, portefølje og produkt kan verke saman som styrings- og leveranseformer.
