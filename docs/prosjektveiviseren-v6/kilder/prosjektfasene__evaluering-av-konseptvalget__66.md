# Evaluering av konseptvalget

Virksomheten bør evaluere om konseptvalget var riktig.

Opprettet: 08. april 2022
Sist endret: 12. juni 2026

Evalueringen skal gi læring om beslutningen som lå til grunn for prosjektet. Den bør vurdere om konseptet var relevant, om målene ble nådd, om forventet nytte eller gevinstpotensial ble realisert, og om de viktigste forutsetningene fra konseptfasen holdt. Herunder om tiltaket har bidratt til ønskede virksomhetsmål og samfunnsmål, og om nytten står i rimelig forhold til kostnadene og ulempene ved tiltaket.
Dersom prosjektet har gått over i produktorganisering, bør evalueringen også vurdere om denne organiseringen støtter videre utvikling og realisering av nyttevirkninger. Erfaringene kan gi viktig læring for fremtidige valg mellom prosjekt-, produkt-, program- eller linjeorganisering.
Formålet er ikke bare å vurdere prosjektet i etterkant, men å gjøre virksomheten bedre til å velge riktige konsepter og gjennomføringsformer i fremtidige tiltak.
**Evalueringen av konseptvalget bør vurdere:**

- om valgt konsept løste riktig problem
- om målene og plan for nyttevirkninger (gevinster) var realistiske
- om kostnader, risiko og forutsetninger ble riktig vurdert
- om andre konsepter burde vært valgt
- om valgt gjennomføringsform var egnet
- om produktorganisering eller annen videre organisering for oppfølging i linjen fungerer godt
- hvilke erfaringer og anbefalinger virksomheten bør bruke i senere konseptvalg
- hvilke anbefalinger som bør følges opp videre
