# Beskrive behovet for endringer i virksomhetens arbeidsprosesser og organisering

Prosjektet må beskrive hvilke endringer som trengs for at produktene skal tas i bruk og gi ønsket nytte. Det kan gjelde arbeidsprosesser, ansvar, roller, kompetanse, rutiner, organisering og ledelsesoppfølging.

Opprettet: 25. mars 2022
Sist endret: 12. juni 2026

Beskriv hvilke prosesser som påvirkes, hva som må endres, hvem som får nye oppgaver, og hvilke deler av linjeorganisasjonen som må involveres. Vurder også hvordan mennesker blir berørt av endringen, for eksempel gjennom nye arbeidsmåter, endrede roller, behov for opplæring, kommunikasjon, medvirkning, ledelsesforankring og støtte i overgangen fra dagens situasjon til ny praksis.
Dersom virksomheten skal etablere produktteam etter prosjektet, bør dette vurderes allerede i planleggingsfasen. Det må være tydelig hvem som skal eie produktet, hvem som skal prioritere videreutvikling, og hvordan produktet skal forvaltes etter at prosjektet er avsluttet.
**Beskrivelsen av virksomhetens arbeidsprosesser og organisering bør avklare:**

- hvilke arbeidsprosesser som påvirkes
- hvilke organisatoriske endringer som trengs
- hvilke roller og ansvar som endres
- hvilke kompetansebehov som oppstår
- hvordan linjen skal involveres
- om det skal etableres produktteam eller annen varig organisering
- hvordan endringene skal følges opp i plan for nyttestyring
