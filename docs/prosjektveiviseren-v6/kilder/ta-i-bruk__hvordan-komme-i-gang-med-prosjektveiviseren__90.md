# Hvordan komme i gang med Prosjektveiviseren?

Begynn enkelt, og tilpass bruken av modellen etter behov. Prosjektveiviseren skal hjelpe prosjektet fremover, ikke skape unødvendig arbeid.

Opprettet: 07. juni 2022
Sist endret: 15. juni 2026

Start med å avklare hvilket behov eller problem som skal løses, hva virksomheten ønsker å oppnå, og hvem som må involveres for å forstå situasjonen. Avklar hvem som eier prosjektet, hvem som leder prosjektet, hvilke fagmiljøer som må bidra, og hvordan brukere og interessenter skal involveres.
Velg deretter riktig ambisjonsnivå. Et lite prosjekt kan klare seg med korte beskrivelser og enkel oppfølging. Et større eller mer komplekst prosjekt trenger mer struktur, mer dokumentasjon og tydeligere beslutningsgrunnlag.
I de tidlige fasene bør prosjektet beskrive mål, behov, forventet nytteverdier (gevinster), usikkerheter og rammer for videre arbeid. Det er ikke nødvendig å planlegge alt i detalj før prosjektet starter. Det viktigste er å ha nok retning og styring til å undersøke behovene, vurdere mulige konsepter og forberede gode beslutninger.
Underveis bør prosjektet bruke det som gir verdi, forenkle der det er mulig og justere arbeidet når ny innsikt kommer. Prosjektveiviseren bør brukes aktivt, men ikke slavisk.
