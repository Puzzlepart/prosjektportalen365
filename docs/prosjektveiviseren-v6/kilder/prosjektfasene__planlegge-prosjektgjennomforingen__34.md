# Planlegge prosjektgjennomføringen

Prosjektgjennomføringsplanen bør forklare hvordan prosjektet skal styres, levere produkter og følge opp mål. Den bør beskrive prosjektets styringsparametre: Tid, kostnad, kvalitet, omfang, usikkerhet, bærekraft og nyttevirkninger (gevinster)

Opprettet: 25. mars 2022
Sist endret: 12. juni 2026

Planen kan også gi føringer for hvordan prosjekteier, prosjektleder og nytteansvarlig skal samarbeide om å følge opp styringsparametere, plan for nyttestyring og eventuelle avvik fra forventet nytte.
Gjennomføringsfasen kan deles inn i delfaser, leveranser og / eller sykluser / iterasjoner dersom det gir bedre styring og kontroll. Prosjektet bør vurdere hvilke deler av arbeidet som egner seg for smidig utvikling (sykluser / iterasjoner), og hvilke deler som bør gjennomføres mer sekvensielt (fossefall). Noen leveranser kan kreve faste avklaringer, anskaffelser eller godkjenninger før videre arbeid, mens andre kan utvikles gjennom korte læringssløyfer, testing og justering.
Dersom prosjektet kombinerer fossefall (sekvensielle) og iterative (smidige) leveranser, må roller, avhengigheter og beslutningspunkter beskrives tydelig.
Planleggingen bør gi rom for læring og endring ved at teamene kan justere løsningen basert på innsikt og tilbakemeldinger, men også ha tydelige mål, prioriteringer, rammer og beslutningspunkter. Planleggingsfasen bør få på plass hvordan teamene skal prioritere, involvere brukere, håndtere endringer og rapportere fremdrift. Dersom Scrum brukes, er Sprint 0 egnet til å etablere dette grunnlaget.
**Planen for prosjektgjennomføring bør omfatte:**

- prosjektets mål, produkter og avgrensninger
- Hvilke deler av prosjektet som skal gjennomføres sekvensielt (fossefall), iterativt (smidig) eller som en kombinasjon. Herunder inndeling i eventuelle delfaser for gjennomføring med milepælsmål eller overordnet plan for iterasjoner.
- styringsparametere med toleranser: Forventet nivå, minste akseptable nivå og vurdering av smidig handlingsrom for tid, kostnad, kvalitet, omfang, bærekraft, nyttevirkninger og risiko
- ressursbehov og kostnader
- roller, ansvar og rapportering
- produktkø eller leveranseplan
- regler for prioritering og endringshåndtering
- plan for brukerinvolvering
- usikkerhet, avhengigheter og tiltak
- gjennomføringsstrategier
- plan for overlevering til linjen
- plan for realisering av nyttevirkninger (gevinstrealisering)
