## Skjermede prosjekter

Statusrapporter, øyeblikksbilder og prosjektinformasjon lagres på porteføljeområdet, og alle som kan lese porteføljeområdet, kan lese dem for alle prosjekter. Noen prosjekter trenger at bare prosjektets deltakere og noen få andre ser dem. Det nye prosjekttillegget `Skjerming` (`Shielding` på engelske huber) gjør det.

**Hva et skjermet prosjekt gjør annerledes:**

| | Vanlig prosjekt | Skjermet prosjekt |
|---|---|---|
| Statusrapporter, også utkast | `Prosjektstatus` på porteføljeområdet | `Prosjektstatus` på prosjektområdet |
| Øyeblikksbilder og frosne seksjonsdata | `Prosjektstatusvedlegg` på porteføljeområdet | `Prosjektstatusvedlegg` på prosjektområdet |
| Prosjektegenskaper | `Prosjektegenskaper` på prosjektområdet, kopiert til `Prosjekter` på porteføljeområdet | Bare `Prosjektegenskaper` på prosjektområdet |
| Arkiveringslogg | `Arkiveringslogg` på porteføljeområdet | `Arkiveringslogg` på prosjektområdet |
| Tidslinjeelementer | `Tidslinjeinnhold` på porteføljeområdet | Kan ikke registreres |
| `Logg` | Porteføljeområdet | Porteføljeområdet, som før |

Listene på prosjektområdet har samme navn og innholdstyper som på porteføljeområdet, også malens egne innholdstyper og felt. Konfigurasjonen, som statusseksjoner, kolonner og maler, leses fortsatt fra porteføljeområdet.

**Slik tar dere det i bruk:**

- Koble tillegget `Skjerming` til malene som skal være skjermet i `Maloppsett` (kolonnen `Utvidelser`), og huk av for `Lås valgte utvidelser?`, så tillegget ikke kan velges bort
- Legg dem som skal se skjermede prosjekter, inn i `Porteføljeinnsyn`. Installasjonen legger til en rad for gruppen i `Tillatelseskonfigurasjon` med det nye omfanget «Skjermede lister», som gir lesetilgang til listene over og ingenting annet på prosjektområdet. Dere kan legge til flere grupper på samme måte
- Prosjektets deltakere trenger bare `Minimum lesetilganger på hub` på porteføljeområdet. Den som oppretter prosjektet, må være leser eller medlem på porteføljeområdet

**Verdt å vite:**

- Gruppene i «Skjermede lister» kopieres til prosjektområdet når prosjektet opprettes. Senere endringer i gruppen på porteføljeområdet når ikke prosjekter som er opprettet. En gruppe som er tom på porteføljeområdet, hoppes over
- Innsynsgruppen ser skjermede prosjekter i ledervisningen i `Porteføljeoversikt`, i statuskolonnen, i `Prosjektliste` og i prosjektinformasjonspanelet, men kan ikke åpne prosjektområdet
- Porteføljen finner skjermede prosjekter og statusrapporter via søk, så endringer vises etter noen minutter. Statuskolonnen viser bare felt som har en kolonne i `Prosjektkolonner`
- Eksisterende prosjekter kan få tillegget med `Kjør oppsettveiviser`, men data som allerede ligger på porteføljeområdet, flyttes ikke. Skjerming kan ikke fjernes fra et prosjekt
- Et program som ikke er skjermet, lagrer navn og adresse til skjermede underprosjekter i `GtChildProjects` som før
- Tilgangene i `Minimum lesetilganger på hub` til `Prosjektstatus`, `Prosjektstatusvedlegg` og `Tidslinjeinnhold` trengs ikke for skjermede prosjekter
